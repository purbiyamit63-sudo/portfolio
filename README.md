# Meet Purbiya — Developer Portfolio

A responsive, animated single-file portfolio using Meet Purbiya's profile, education, skills, and project details.

## Features

- The complete website is contained in `index.html`, including styles, animations, language data, and images.
- Responsive layout, animated project cards, custom cursor, and interactive skill badges.
- Dark and blue-tinted light themes.
- English, Gujarati, and Hindi navigation and hero language options.
- Profile, education, skills, projects, and contact sections.
- No PHP server, database, or asset folders required.

## Publish with GitHub Pages

1. Upload `index.html` to the root of the GitHub repository's `main` branch.
2. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then save.
3. Open the website link shown in the Pages settings after deployment completes.

Project descriptions are based on the supplied reference and describe the projects as concepts. The reference did not include contact email or social links.
